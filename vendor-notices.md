# Browser library notices

The QR encoder is installed from the pinned npm dependency `qrcode-generator@2.0.4` and copied into `public/vendor/qrcode.js` during the build. Its license notice is copied to `public/vendor/qrcode-LICENSE.txt`. QR images are generated locally; classroom links are not sent to a QR-image service.

- qrcode-generator 2.0.4: MIT License, https://github.com/kazuhikoarase/qrcode-generator/blob/master/LICENSE

The application backend uses the Netlify Blobs SDK from the pinned `@netlify/blobs` npm dependency.
